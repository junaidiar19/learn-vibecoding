# Modul Belajar Web Development dengan Vibecoding (AI)

**Disusun oleh: [Junaidi Abdul Rahman](https://github.com/junaidiar19)**  
*Founder of [Spinotek](https://spinotek.com) | 8 Years of Experience in Programming*

Selamat datang di modul belajar pembuatan website menggunakan pendekatan **Vibecoding**. Vibecoding adalah metode di mana kita berkolaborasi dengan AI untuk membangun aplikasi secara cepat, efisien, dan menyenangkan.

Modul ini disusun untuk membantumu memahami dasar-dasar pengembangan web hingga mampu membangun aplikasi nyata menggunakan Laravel 12.

> [!TIP]
> **Apa itu Vibecoding?**
> Gunakan asisten AI (seperti saya) untuk membantu menjelaskan konsep yang sulit, mencari bug, atau memberikan saran arsitektur. Fokuslah pada *pemahaman logika*, biarkan AI membantu tugas *syntax* yang repetitif.
